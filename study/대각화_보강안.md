# Ⅳ장 대각화 보강안

## 진단

공지의 Ⅳ장 요구는 "특성방정식, 대각화 등"입니다. 현재 보고서에서 대각화는 다음과 같습니다.

- Ⅱ장 식 (1) `A = QΛQᵀ`로 **서술만** 되어 있습니다.
- Ⅳ장은 특성방정식을 풀고(`x⁴ − 3x² + 1`), 고유값 4개를 구하고, **고유벡터는 x = g 하나만** 구합니다. 나머지는 "같은 방법으로 구하면 [그림 3]을 얻는다"로 넘어갑니다.
- 직교행렬 Q를 실제로 만들어 `QᵀAQ = Λ`를 확인하는 부분이 **없습니다.**
- 공지가 강조한 "벡터공간" 개념도 본문에 드러나지 않습니다.

그래서 "대각화를 했다"고 말할 수 있는 내용이 비어 있다는 지적이 맞습니다.

## 넣을 내용: Ⅳ장 새 소절 "□ 뷰타다이엔의 대각화" (식 (12) 뒤, "π 전자 에너지" 소절 앞)

### 본문 초안

> 앞에서 구한 고유값 x = g, g⁻¹, −g⁻¹, −g 각각에 대해 같은 방법으로 단위 고유벡터를 구하고, 이를 열로 하는 행렬을 Q라 하자(식 (a)). 인접행렬 A는 실대칭행렬이므로 서로 다른 고유값의 고유벡터는 서로 수직이며, Q는 직교행렬(QᵀQ = I)이다. 따라서 A는 식 (b)와 같이 대각화된다.
>
> 대각화 결과를 화학의 언어로 읽으면 다음과 같다. Λ의 대각성분은 네 분자궤도의 에너지 층(E = α + xβ의 x)이고, Q의 각 열은 해당 분자궤도의 계수 벡터이다. 즉 대각화 한 번으로 네 분자궤도와 에너지를 한꺼번에 얻는다. 첫째 열이 앞에서 구한 ψ₁의 계수 (0.372, 0.602, 0.602, 0.372)이다.
>
> 계산이 맞는지 두 가지로 확인하였다. 첫째, 대각합이 보존된다. tr A = 0이므로 고유값의 합도 0이다. tr A² = 6은 결합 수 3의 두 배이며, 고유값의 제곱합 2(g² + g⁻²) = 2 × 3 = 6과 같다. 둘째, numpy로 QᵀAQ와 Λ를 비교하면 오차가 10⁻¹⁵ 수준이다.
>
> 벡터공간의 관점에서 보면, 네 고유벡터는 ℝ⁴의 직교기저이다. 따라서 분자 속 π 전자의 임의의 상태는 네 분자궤도의 선형결합으로 나타낼 수 있다.

### 한글 수식 편집기에 붙여 넣을 스크립트

(a) Q (열 = 고유벡터, 첫째 열이 x = g)
```
Q = LEFT ( matrix { 0.372 & 0.602 & 0.602 & 0.372 # 0.602 & 0.372 & -0.372 & -0.602 # 0.602 & -0.372 & -0.372 & 0.602 # 0.372 & -0.602 & 0.602 & -0.372 } RIGHT )
```

Λ
```
LAMBDA = rm diag ( g , g^{-1} , -g^{-1} , -g )
```

(b) 대각화
```
Q^{T} A Q = LAMBDA , ~~~~ A = Q LAMBDA Q^{T}
```

### 검증 근거 (이 세션에서 계산)
- 고유값(큰 것부터): 1.618, 0.618, −0.618, −1.618
- `Q = √(2/5) · sin(jkπ/5)` (j: 행, k: 열)와 numpy 결과가 일치
- `‖QΛQᵀ − A‖max = 8×10⁻¹⁶`
- tr A = 0, tr A² = 6 (= Σx² = 2(g² + g⁻²))

### 선택: Python 검증에 한 줄 추가 (Ⅴ장)
```python
w, Q = np.linalg.eigh(path(4))
print(np.abs(Q.T @ path(4) @ Q - np.diag(w)).max())   # 약 1e-15
```
