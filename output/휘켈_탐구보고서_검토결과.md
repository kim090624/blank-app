## 수정 전후 논리 구성

- **전**: 연결 구조 → 인접행렬 → H = αI + βA → 고유값 → 사슬·고리 일반식 → 4m + 2 규칙 → 결론.
- **후**: 흐름은 유지했다. 달라진 점은 세 가지다.
  1. H = αI + βA가 성립하는 조건이 먼저 제시된다.
  2. 고리에서 닫힌 껍질이 만들어지는 조건이 정확해졌다(k = 0과 k = n/2 예외).
  3. 4n + 2 규칙이 모델의 결과이며 판정 규칙이 아님을 명시하고 DE 비교의 한계를 결론에 반영했다.
